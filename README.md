# Abdelmaskoud Ibrahim El-sharkawy Portfolio

A static English portfolio for a Flutter developer.

## Run

Open `index.html` directly in your browser, or serve the folder with any simple local server.

## Customize

- Replace `hello@example.com` in `index.html` and `script.js`.
- Update the GitHub and LinkedIn links in `index.html`.
- Replace the project examples with real Flutter apps.
- Adjust colors from the `:root` variables in `styles.css`.
